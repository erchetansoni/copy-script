# Copy Master - Legacy Edition (PowerShell 5.1 & WPF)

> **Archived & Preserved for Reference**  
> This directory contains the original Windows PowerShell 5.1 and WPF desktop GUI implementation.

## Files
- `CopyMaster-UI.ps1`: WPF Desktop GUI configurator.
- `CopyScript.ps1`: Robocopy and PowerShell replication template.
- `SecurityProtocols.ps1`: Cryptography and remote server security guides.
- `Install-Task.ps1`: Windows Scheduled Task installer.
- `Test-CopyMaster-E2E.ps1`: 21-point automated End-to-End test suite.
- `Launch-CopyMaster.bat`: Elevated UAC launcher for the WPF GUI.

## Modern Go Edition
For the standalone, air-gapped, cross-platform implementation (with Bubble Tea, Bubbles, Lip Gloss, and Huh), see the `go/` directory.
